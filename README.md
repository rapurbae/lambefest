# lampefest.com

Landing page "Coming Soon" untuk **Lampefest** — festival musik dari Lambe.

- **Tema:** neon magenta / cyan / sunset — energi festival ala *"Spill The Beat. Feel The Heat."*
- **Fitur:** countdown menuju hari-H (Summer 2027, Nuanu Bali), form "Ingatkan Saya" (email), tombol "Set Reminder" (Google Calendar), marquee strip.
- **Domain:** [lampefest.com](https://lampefest.com)

## Struktur

```
index.html    — struktur halaman
styles.css    — tema neon festival
script.js     — countdown, form notifikasi, link kalender
assets/img/   — hero & foto pendukung (Unsplash)
```

## Aset

Foto dari Unsplash — kredit fotografer ada di komentar `index.html` / halaman situs. Ganti `LAUNCH` di `script.js` untuk mengubah tanggal hari-H.

## Deploy

Static site — deploy via Vercel (repo GitHub: `rapurbae/lampefest`).
