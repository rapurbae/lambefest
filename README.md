# lambefest.com

Landing page "Coming Soon" untuk **Lambefest** — festival musik dari Lambe.

- **Tema:** neon magenta / cyan / sunset — energi festival ala *"Spill The Beat. Feel The Heat."*
- **Fitur:** form "Ingatkan Saya" (email), tombol "Set Reminder" (Google Calendar), marquee strip.
- **Domain:** [lambefest.com](https://lambefest.com)

## Struktur

```
index.html    — struktur halaman
styles.css    — tema neon festival
script.js     — form notifikasi, link kalender
assets/img/   — hero & foto pendukung (Unsplash)
```

## Aset

Background hero: "festival crowd under stage lights" — Yvette de Wit (@yvettedewit), Unsplash License. Kredit lengkap ada di komentar `index.html`. Ganti `LAUNCH` di `script.js` untuk mengubah tanggal hari-H.

## Deploy

Static site — deploy via Vercel (repo GitHub: `rapurbae/lambefest`).
